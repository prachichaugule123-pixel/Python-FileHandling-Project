# Student Record Management System

## Overview

This mini project is a menu-driven Student Record Management System developed using Python and File Handling. It allows users to manage student records efficiently by storing data in text files. The system supports adding, searching, updating, deleting, sorting, and backing up student records while demonstrating practical applications of file operations.

## Objectives

- Add student records containing Name, Roll Number, and Marks.
- Save student information permanently using file handling.
- Search for a student using their Roll Number.
- Update the marks of an existing student.
- Delete a student record by Name or Roll Number.
- Display all student records sorted by marks.
- Show students who scored more than 75 marks.
- Export the top 3 performing students to a separate file.
- Create a backup of all student records in `backup.txt`.
- Count the number of students who scored:
  - More than 90 marks
  - Less than 35 marks
- Provide a user-friendly menu-driven interface for managing records.
